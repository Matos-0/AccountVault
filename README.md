# Account Vault

Sistema de armazenamento e gerenciamento de credenciais de acesso para sites, aplicações, plataformas e contas em geral.

O **AccountVault** foi desenvolvido com foco em simplicidade, organização e escalabilidade, oferecendo uma base para gerenciamento seguro de logins e credenciais utilizando arquitetura moderna com Node.js + TypeScript.

---

## Tecnologias Utilizadas

### BackEnd
- Node.js
- TypeScript
- Express
- Armazenamento local em arquivos JSON

### FrontEnd
- HTML5
- CSS3
- JavaScript

---

## Arquitetura

O projeto segue conceitos de:

- Layered Architecture
- Clean Architecture
- Separação de responsabilidades
- Organização modular
- Estrutura preparada para escalabilidade
